# Suguru Studio

L'application de Suguru IA pour Windows : chat multi-modèles, agent qui travaille dans tes projets
(avec ton accord pour chaque action sensible), terminal, Git, tâches planifiées, skills et plugins
repris de Claude Code et de Codex.

Ce dépôt ne contient **que les versions publiées**. Le code source est privé.

## Installer

1. Ouvre l'onglet **[Releases](../../releases/latest)** et télécharge `Suguru-Studio-Setup-<version>.exe`.
2. Lance-le. Windows peut afficher « éditeur inconnu » : l'installeur n'est pas encore signé par un
   certificat de signature de code. Clique sur « Informations complémentaires » puis « Exécuter quand même ».
3. Au premier lancement, choisis un pseudo.

Suguru Studio se met ensuite à jour tout seul à partir de ce dépôt : chaque mise à jour est vérifiée par
son empreinte SHA-512 avant d'être installée.

## Tes données

Tes projets et tes conversations restent sur ton PC (par défaut dans `E:\Suguru Studio`, ou dans tes
Documents s'il n'y a pas de disque E:). Rien de ce que tu écris ne sert à entraîner Suguru IA sans ton
accord explicite, que tu peux retirer à tout moment dans Paramètres → Consentements.
